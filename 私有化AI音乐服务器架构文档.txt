私有化AI音乐服务器·全模块关联闭环架构文档
（Web + APP + Docker + AI + TCP）

════════════════════════════════════════════════════════════════
核心设计逻辑
════════════════════════════════════════════════════════════════
全程链路闭环 + 模块强关联 + 权限严格隔离 + 双端数据互通

整体链路：
  登录鉴权 → 前台用户功能（首页/发现/曲库/歌单/播放）
         → 个人中心权限分流 → 管理员后台配置支撑
         → AI服务全局赋能 → API + TCP 双通道对接 Web/APP
         → Docker 容器化整体部署

核心原则：
  · 所有前端展示功能，全部依赖后台配置
  · 所有AI推荐功能，全部联动用户行为数据
  · 所有端侧操作，全部实现多端实时同步，100% 无功能割裂


════════════════════════════════════════════════════════════════
一、全局底层核心体系（所有模块的基础支撑）
════════════════════════════════════════════════════════════════
为全页面、全功能、双端（Web/APP）提供底层支撑，
所有上层功能全部依赖此模块，是系统运行核心底座。

1.1 权限体系（核心隔离逻辑）
  · 双角色划分：普通用户 / 管理员
  · 普通用户：仅拥有使用权限（听歌、看推荐、管理个人歌单/收藏、个人设置），
    无任何系统配置权限
  · 管理员：拥有全量使用权限 + 系统配置权限，可进入后台管控全站
  · 权限分流入口：顶部头像下拉菜单、个人中心底部入口
    （普通用户隐藏后台入口）

1.2 双数据通信通道（全局端侧互通）
  · REST API（HTTP）：承载所有静态数据请求、页面渲染、常规操作，
    支撑 Web 全功能、APP 基础数据拉取
  · TCP 长连接（专属核心）：单通道保活，专属手机 APP，
    承载实时播放同步、AI 推送、状态互通、消息通知，低功耗弱网适配
  · 双通道联动：API 负责数据落地存储，TCP 负责实时推送展示，
    实现 Web/APP 多端操作秒同步

1.3 容器化部署底座
  · 全服务 Docker 镜像打包，一键部署、迁移、备份
  · 支持宿主机音乐目录挂载，实现本地曲库实时接入系统
  · 数据库（PostgreSQL + Redis）独立持久化，
    所有用户数据、曲库数据、AI 数据、播放数据统一存储

1.4 全局通用组件（所有页面复用）
  · 全局顶部栏：Logo、全站搜索（歌曲/歌手/专辑/歌单）、个人头像权限入口
  · 全局底部导航（常驻三 Tab）：首页、发现、我的
    （统一 Web/APP 页面结构）
  · 全局底部播放器：所有页面通用，常驻不销毁，
    统一播放控制、队列管理、歌词展示


════════════════════════════════════════════════════════════════
二、入口层：登录注册模块（系统唯一准入，权限初始化）
════════════════════════════════════════════════════════════════
所有用户操作的前置入口，完成身份校验、权限分配，
直接关联后续所有页面功能。

2.1 核心功能
  · 多方式登录：账号密码、手机/邮箱验证码、记住登录状态
  · 访客模式：免登录浏览公开曲库，无个人数据留存
  · 注册管控：管理员后台可开关开放注册、配置邀请码注册
  · 登录后自动分流：所有用户统一进入首页，
    后台入口按角色隐藏/展示

2.2 模块关联
  · 登录鉴权成功后，加载对应用户权限、个人数据、播放历史、AI 偏好，
    初始化首页推荐内容，联动全局权限体系


════════════════════════════════════════════════════════════════
三、用户前台核心功能层（普通用户/管理员通用）
════════════════════════════════════════════════════════════════
所有登录用户可使用的核心业务功能，
页面层层联动、数据互通，AI 全局赋能。

3.1 首页（个性化推荐总入口）
  · 数据完全联动：AI 推荐模块 + 用户个人行为 + 全网热榜模块
  · 轮播 Banner：展示新歌、AI 专题、官方推荐（后台可配置）
  · 最近播放：同步多端播放历史，支持断点续播
  · 今日 AI 推荐歌单：由后台 AI 服务每日自动生成，
    基于用户听歌画像定制
  · 新歌速递：同步后台曲库扫描新增歌曲
  · 热榜快速预览：联动全网热榜数据，标注本地曲库有无状态

3.2 发现页（公共内容总广场）
  · 聚合全站公共资源，联动热榜爬虫、AI 生成、曲库全量数据
  · 全网热歌排行榜：日/周/月榜、语种/风格分类榜
  · 核心特色：每首歌联动本地曲库，标注 ✅ 已收录 / ❌ 本地暂无
  · 支持批量处理缺失歌曲、收藏榜单、一键播放
  · 歌单广场：官方精选、AI 自动生成、用户公开歌单，
    支持收藏、分享、导入导出
  · AI 智能推荐中心：独立 AI 功能聚合页（全文最核心智能模块）
  · 全维度曲库浏览：按风格、场景、语种筛选曲库内容

3.3 曲库中心（歌手 - 专辑 - 歌曲 三级闭环体系）
  · 系统曲库核心载体，所有播放、收藏、推荐、歌单功能均基于此模块
  · 歌曲库：全量歌曲浏览、筛选、排序、批量操作，
    联动元数据修复模块
  · 歌手库：歌手主页、全部专辑、热门单曲、相似歌手推荐（AI 联动）
  · 专辑库（完整独立体系）：专辑封面墙、筛选分类、专辑详情、
    曲目列表、专辑收藏、相似专辑推荐
  · 文件夹视图：完全映射后台挂载的本地目录，保留本地文件结构

3.4 个人歌单模块（用户私有内容体系）
  · 完全关联用户个人数据，联动播放、收藏、AI 生成歌单功能
  · 自定义歌单：创建、编辑、删除、设置公开/私有、自定义封面
  · 歌单详情操作：播放全部、随机播放、增删歌曲、
    拖动排序、批量管理
  · 歌单导入导出：支持主流格式和平台链接解析
  · AI 歌单一键保存：将 AI 生成的临时歌单转为个人永久歌单

3.5 个人中心（用户数据总聚合）
  · 汇总所有个人行为数据，权限分流核心页面
  · 个人资料：头像、昵称、签名等自定义设置
  · 数据统计：听歌时长、收藏数量、风格画像（AI 分析结果展示）
  · 全套收藏体系：收藏歌曲/专辑/歌手/歌单（四维度收藏闭环）
  · 播放历史：多端同步历史记录，支持分类查看、一键清空
  · 个人设置：播放、外观、缓存、通知、AI 偏好自定义
  · 权限专属：管理员可见【后台管理入口】，普通用户无此权限

3.6 全局播放器（全功能播放闭环）
  · 联动所有页面歌曲资源，同步多端播放状态，支撑全部听歌场景
  · 迷你常驻播放器 + 全屏播放器双模式
  · 完整播放控制：模式切换、进度调节、音质/速度调节、定时关闭
  · 逐行歌词、专辑封面展示、歌曲详情查看
  · 播放队列管理、历史队列回溯、队列存为歌单
  · 多端实时同步：依托 TCP + API 双通道，Web/APP 播放进度、
    队列、状态完全互通

3.7 全局搜索模块（全站资源统一检索）
  · 打通曲库、歌单、歌手、专辑、全网热榜所有资源
  · 实时联想搜索、关键词高亮匹配
  · 分类结果展示：综合 / 歌曲 / 歌手 / 专辑 / 歌单 / 全网
  · 搜索历史、热门热搜，联动全网热榜数据
  · 全网搜索结果标注本地有无，闭环补齐曲库资源


════════════════════════════════════════════════════════════════
四、AI 智能核心模块（全局赋能所有前端功能）
════════════════════════════════════════════════════════════════
权限严格隔离：后台配置，前台使用；
所有 AI 能力统一由管理员配置，用户仅自定义偏好。

4.1 后台 AI 底层配置（管理员专属）
  · 多模型接入：云端 API（DeepSeek / 千问等）+ 本地私有化模型双兼容
  · 密钥管理、模型限流、调用统计、热切换配置
  · 热榜爬虫配置：数据源、更新频率、数据聚合规则
  · 推荐策略配置：更新时间、推荐数量、算法权重、冷启动规则

4.2 前台 AI 落地功能（用户通用）
  · 每日个性化推荐：基于用户播放、收藏、跳过行为生成专属歌单
  · 自然语言生成歌单：输入场景/情绪描述，AI 自动匹配歌曲生成歌单
  · 相似推荐：相似歌曲、歌手、专辑智能匹配
  · 全网热歌推荐：聚合全网热搜，匹配本地曲库做缺失补齐
  · 用户听歌画像：自动分析偏好风格、语种、时段，生成个人听歌报告

4.3 模块关联逻辑
  · AI 模块读取用户播放数据、收藏数据、曲库数据、全网热榜数据，
    计算后生成推荐结果，同步展示在首页、发现页、歌曲详情页，
    结果可直接加入播放队列 / 个人歌单，完全闭环


════════════════════════════════════════════════════════════════
五、管理员后台模块（全系统底层管控，支撑所有前台功能）
════════════════════════════════════════════════════════════════
所有前台展示、AI 运行、曲库数据、用户权限，
全部由后台配置驱动；无后台配置则前台功能无法生效。

5.1 系统仪表盘（全局数据总览）
  · 汇总曲库、用户、播放、系统运行、存储所有数据

5.2 曲库管理（系统资源核心）
  · 目录挂载：配置宿主机音乐文件夹映射，支撑本地曲库接入
  · 扫描管理：自动/手动增量/全量扫描，同步本地文件到系统曲库
  · 资源修复：自动补全歌曲/专辑/歌手信息、封面、歌词，
    修复乱码损坏文件
  · 曲库运维：重复文件检测、冗余数据清理、批量编辑元数据

5.3 用户与内容管控
  · 用户管理：增删用户、权限分配、账号管控、密码重置
  · 歌单管理：官方歌单编辑、用户公开歌单审核、首页推荐置顶

5.4 网络与服务管控
  · 站点基础配置：Logo、名称、注册开关、版权信息
  · 公网访问、HTTPS、反向代理、IP 黑白名单、接口限流
  · TCP 服务配置：端口、心跳、连接数管控、实时连接监控

5.5 运维保障
  · 全量日志：系统日志、操作日志、播放日志、错误日志
  · 数据备份恢复：自动/手动备份、配置导入导出
  · 性能监控：CPU / 内存 / 磁盘 / 存储空间趋势监控


════════════════════════════════════════════════════════════════
六、手机 APP 端模块（与 Web 端 100% 数据互通，专属 TCP 通道）
════════════════════════════════════════════════════════════════
所有功能完全对齐 Web 前台，依托双通信通道实现跨端闭环，
新增移动端专属能力。

6.1 同步 Web 全功能
  · 首页推荐、热榜、歌单广场、AI 推荐、曲库、个人中心、搜索、
    播放器全部同步，数据实时互通

6.2 APP 专属功能
  · 离线歌曲缓存、后台播放、锁屏/蓝牙/车载适配
  · 流量节省模式、夜间模式、桌面小组件、扫码登录

6.3 TCP 长连接核心价值
  · 替代 HTTP 轮询，单通道低功耗保活，实现播放状态、推荐更新、
    消息推送、队列同步秒级互通，适配移动端弱网场景


════════════════════════════════════════════════════════════════
七、全系统最终关联闭环总结（无漏洞逻辑）
════════════════════════════════════════════════════════════════
· 底层支撑上层：Docker 部署、数据库、双通信通道、权限体系，
  支撑所有页面功能运行
· 后台支撑前台：所有曲库资源、AI 模型、系统参数、用户权限，
  全部由后台配置，前台仅做展示和使用
· 行为驱动 AI：用户播放、收藏、听歌偏好数据，输入 AI 模型，
  生成个性化推荐反哺首页和发现页
· 曲库支撑所有内容：歌单、推荐、热榜、播放、收藏，
  全部基于歌手-专辑-歌曲三级曲库体系
· 双端完全互通：Web 与 APP 数据、状态、操作实时同步，
  TCP 负责实时、API 负责落地
· 权限绝对隔离：普通用户只用功能、不改配置；
  管理员全权管控、配置全局，无权限混乱 BUG
· 资源闭环补齐：全网热榜识别本地缺失歌曲，AI 推荐联动本地曲库，
  实现曲库持续完善迭代
